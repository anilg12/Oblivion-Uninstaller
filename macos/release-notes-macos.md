### 🍏 macOS (yeni!)
Mac için sıfırdan, Swift/SwiftUI ile yazılmış yerel sürüm — Windows'taki tüm bölümler ve tasarım.
- 🖥️ macOS 14 Sonoma / 15 Sequoia / 26 Tahoe · Apple Silicon (M1–M4) ve Intel
- 🧹 Kaldırırken Library klasörlerindeki ayar, önbellek, profil ve başlangıç kalıntılarını bulur; önce Çöp Sepeti'ne atar

**En kolay kurulum (uyarısız, tek satır):** Terminal'i aç, şunu yapıştır, Enter'a bas:
```
curl -fsSL https://raw.githubusercontent.com/anilg12/Oblivion-Uninstaller/main/macos/install-mac.sh | bash
```
**Ya da** `Oblivion-2.0.0-macOS.dmg` dosyasını indir → Oblivion'u **Applications**'a sürükle → ilk açılışta **Sistem Ayarları → Gizlilik ve Güvenlik → Yine de Aç**.

Native macOS version written from scratch in Swift/SwiftUI, with every section and the same design as on Windows.

- Finds settings, cache, profile and launch-item leftovers in the Library folders; everything goes to the Trash first

**Easiest install (no warning, one line):** open Terminal, paste, press Enter:
```
curl -fsSL https://raw.githubusercontent.com/anilg12/Oblivion-Uninstaller/main/macos/install-mac.sh | bash
```
**Or** download `Oblivion-2.0.0-macOS.dmg` → drag Oblivion to **Applications** → on first launch use **System Settings → Privacy & Security → Open Anyway**.
